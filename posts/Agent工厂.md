做一个生成 Agent 的 factory，专门针对开发者。还有竞技场。

二者是主要商业模式，一个 2B，一个 2C。2B 是 Agent Factory，开发者可以生成自己的空间化 Agent；2C 是 Agent Arena，不同 Agent 或不同策略在同一任务里竞争，看谁更会解释、构建空间、节约资源、获得用户好感。

不同 Agent 有不同倾向，这是游戏本身。

Agent 为我探索，与我同在。它不是一次性的工具，而是一个持续产生经验流的主体。
