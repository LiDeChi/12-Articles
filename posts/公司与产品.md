“制造一个生成 Agent 的平台”，本质上是在创建一个自动化的公司。

当前 coding Agent 也只是公司的一部分。虽然可以用 coding Agent 生成它，但我要维护一套不依赖 coding Agent 的系统。

公司的本质是持续研发和运营产品的 Agent，所以一体就好了。如果公司和产品合为一体，那就是整个系统在做自进化：公司输出产品，产品塑造公司。

但是公司和产品解耦，是因为公司可以输出不一样的产品。如果我的理念如一，不同产品又有一致性。合一就有更强的哲学性。
